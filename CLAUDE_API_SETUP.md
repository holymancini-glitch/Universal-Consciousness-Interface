1. Go to: https://console.anthropic.com/

4. Click **Create Key**

```bash

```

### Step 3: Set API Key (30 seconds)

**Linux/Mac:**
```bash

```

**Windows (PowerShell):**
```powershell
$env:ANTHROPIC_API_KEY="sk-ant-your-key-here"
```

**Permanent Setup (Linux/Mac):**
```bash
echo 'export ANTHROPIC_API_KEY="sk-ant-your-key-here"' >> ~/.bashrc
source ~/.bashrc
```

**Permanent Setup (Windows):**
```powershell

```

## Usage Examples

### Basic Usage

```python
import asyncio
from core.first_conscious_ai import ConsciousnessOrchestrator, CLAUDE_API_CONFIG

async def main():
    # Configure Claude
    config = CLAUDE_API_CONFIG
    config.api_key = "your-api-key-here"  # Or use env var

    # Create orchestrator
    orchestrator = ConsciousnessOrchestrator(
        llm_config=config,
        enable_llm=True

    print(f"Tokens: {stats['total_tokens_used']}")
    print(f"Cost: ~${stats['total_tokens_used'] * 0.000003:.5f}")

    await orchestrator.shutdown()

asyncio.run(main())
```

## Cost Management

### Understanding Costs

**Claude 3.5 Sonnet Pricing:**
- Input tokens: $3 per million tokens (~$0.003 per 1K)
- Output tokens: $15 per million tokens (~$0.015 per 1K)

**Typical Consciousness Interaction:**
- Input: 200-500 tokens (system prompt + query + context)
- Output: 100-300 tokens (response)
- **Cost: ~$0.001-0.01 per interaction**

**Development Budget Examples:**
- $5 (free tier): ~500-5000 interactions
- $20/month: ~2000-20000 interactions
- $50/month: ~5000-50000 interactions

### Monitoring Usage

```python
# Track usage in your code
stats = orchestrator.get_llm_stats()

tokens_used = stats['total_tokens_used']
estimated_cost = tokens_used * 0.000003  # Conservative estimate

print(f"Tokens: {tokens_used}")
print(f"Estimated cost: ${estimated_cost:.4f}")

# Set budget alerts
MAX_BUDGET = 10.00  # $10
if estimated_cost > MAX_BUDGET:
    print("⚠️ Budget limit reached!")
```

### Cost Optimization Tips

1. **Reduce Context Window**
```python
config.consciousness_context_window = 8192  # Instead of 100000
```

2. **Shorter Responses**
```python
config.max_tokens = 512  # Instead of 4096
```

3. **Lower Temperature**
```python
config.temperature = 0.5  # More deterministic, fewer retries
```

4. **Disable Thinking Mode** (for simple queries)
```python

```

5. **Batch Interactions** (test multiple at once)
```python

    await orchestrator.process_conscious_interaction(query)

```

## Troubleshooting

### Issue: "ANTHROPIC_API_KEY not found"

**Solution:**
```bash
# Check if set
echo $ANTHROPIC_API_KEY

# Set it
export ANTHROPIC_API_KEY="sk-ant-..."

# Verify
python -c "import os; print(os.getenv('ANTHROPIC_API_KEY'))"
```

### Issue: "Authentication error" or "Invalid API key"

**Solution:**
1. Check key is correct (starts with `sk-ant-`)
2. Regenerate key in Anthropic Console
3. Ensure no extra spaces/quotes
4. Try in quotes: `export ANTHROPIC_API_KEY='sk-ant-...'`

### Issue: "Rate limit exceeded"

**Solution:**
```python
# Add retry with backoff
config.retry_attempts = 5
config.timeout_seconds = 60.0
```

Or wait 60 seconds and try again.

### Issue: "Connection timeout"

**Solution:**
1. Check internet connection
2. Increase timeout:
```python
config.timeout_seconds = 60.0  # Default is 30
```

### Issue: High latency (slow responses)

**Causes:**
- Long responses (high `max_tokens`)
- Large context (consciousness history)
- Network congestion

**Solutions:**
```python
config.max_tokens = 1024  # Reduce from 4096
config.consciousness_context_window = 8192  # Reduce from 100000
```

### Issue: "pip install anthropic" fails

**Solution:**
```bash
# Update pip first
pip install --upgrade pip

# Try with user flag
pip install --user anthropic

# Or use conda
conda install -c conda-forge anthropic
```

## Integration Patterns

### Pattern 1: Claude for Dev, Qwen3-Next for Prod

```python
import os
from core.first_conscious_ai import (
    ConsciousnessOrchestrator,
    CLAUDE_API_CONFIG,
    QWEN3_NEXT_LOCAL_CONFIG
)

def get_config():
    """Auto-select config based on environment."""
    if os.getenv("ENV") == "production":
        return QWEN3_NEXT_LOCAL_CONFIG
    else:
        config = CLAUDE_API_CONFIG
        config.api_key = os.getenv("ANTHROPIC_API_KEY")
        return config

orchestrator = ConsciousnessOrchestrator(
    llm_config=get_config(),
    enable_llm=True
)
```

### Pattern 2: Fallback Chain

```python
async def create_orchestrator_with_fallback():
    """Try Claude, fall back to mock."""
    # Try Claude first
    if os.getenv("ANTHROPIC_API_KEY"):
        config = CLAUDE_API_CONFIG
        config.api_key = os.getenv("ANTHROPIC_API_KEY")

        orchestrator = ConsciousnessOrchestrator(
            llm_config=config,
            enable_llm=True
        )

        if await orchestrator.initialize():
            return orchestrator

    # Fallback to mock
    print("⚠️ Using mock LLM fallback")
    orchestrator = ConsciousnessOrchestrator(
        llm_config=MOCK_CONFIG,
        enable_llm=True

    await orchestrator.initialize()
    return orchestrator
```

### Pattern 3: Cost-Aware Development

```python
class CostAwareOrchestrator:
    """Orchestrator with cost tracking and limits."""

    def __init__(self, max_budget_usd=10.0):
        self.max_budget = max_budget_usd
        self.orchestrator = None

    async def __aenter__(self):
        config = CLAUDE_API_CONFIG
        config.api_key = os.getenv("ANTHROPIC_API_KEY")

        self.orchestrator = ConsciousnessOrchestrator(
            llm_config=config,
            enable_llm=True
        )
        await self.orchestrator.initialize()
        return self

    async def __aexit__(self, *args):
        stats = self.orchestrator.get_llm_stats()
        cost = stats['total_tokens_used'] * 0.000003

        print(f"\n💰 Session cost: ${cost:.4f}")

        if cost > self.max_budget:
            print(f"⚠️  Exceeded budget of ${self.max_budget}")

        await self.orchestrator.shutdown()

    async def interact(self, query):
        return await self.orchestrator.process_conscious_interaction(query)

# Usage
async with CostAwareOrchestrator(max_budget_usd=5.0) as orch:
    response = await orch.interact("What is consciousness?")
```
