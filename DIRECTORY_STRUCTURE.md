# Directory Structure

This document describes the organized directory structure of the Universal Consciousness Interface repository.

## Root Directory

Core entry point files and main interfaces:
- `standalone_consciousness_ai.py` - Standalone AI consciousness model
- `unified_consciousness_interface.py` - Main unified consciousness interface  
- `comprehensive_demo.py` - Comprehensive system demonstration
- `setup.py` - Package setup configuration
- `setup_qwen3_production.py` - Qwen3 LLM production setup
